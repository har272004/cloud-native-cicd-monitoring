# Cloud Native CI/CD Monitoring Project

## Overview
This project demonstrates a complete DevOps CI/CD pipeline using Jenkins, Docker, Prometheus, Grafana and Linux.

## Tech Stack
- Linux
- Docker
- Jenkins
- GitHub
- Prometheus
- Grafana
- Node Exporter

## Features
- Automated CI/CD pipeline using Jenkins
- Docker container deployment
- GitHub integration
- Monitoring with Prometheus & Grafana
- Linux server deployment

## CI/CD Flow
GitHub → Jenkins → Docker Build → Container Deployment
